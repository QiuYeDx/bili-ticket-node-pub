# bili-ticket-node

本仓库仅用于发布 bili-ticket-node 的公开说明与 Release 下载，不包含项目源码。

bili-ticket-node 是一个本地运行的学习与研究工具，用于个人理解票务流程、Node.js 工程实践和本地 Web 应用组织方式。它不是商业代抢工具，也不是公网服务。

## 下载与运行

1. 打开本仓库的 Releases 页面。
2. Windows 用户下载 `bili-ticket-node-win-x64` 安装包或压缩包。
3. macOS 用户下载 `bili-ticket-node-mac-x64` 或 `bili-ticket-node-mac-arm64` 安装包或压缩包。
4. 安装或解压后双击运行 bili-ticket-node。
5. 程序会在本机启动服务并打开本地页面。

> Linux 服务器版本和 Docker 镜像暂不在首批 Release 范围内。
